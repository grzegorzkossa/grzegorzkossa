Jestem Java Fullstack Developerem z 11-letnim doświadczeniem w tworzeniu, rozwijaniu i utrzymywaniu aplikacji biznesowych. Specjalizuję się w technologiach Java, Spring Boot, React i TypeScript. Łączę wiedzę backendową z tworzeniem interfejsów użytkownika, integracją systemów oraz projektowaniem rozwiązań odpowiadających na rzeczywiste potrzeby biznesowe.



Moje główne kompetencje:

- Rozwój aplikacji backendowych w Java i Spring Boot.

- Tworzenie interfejsów webowych w React i TypeScript.

- Integracja systemów i synchronizacja danych, szczególnie z Salesforce.

- Projektowanie i implementacja API REST i SOAP.

- Praca z relacyjnymi i nierelacyjnymi bazami danych.

- Testy jednostkowe i integracyjne, refaktoryzacja oraz poprawa jakości kodu.

- Analiza wymagań i współpraca z interesariuszami biznesowymi.

- Wdrażanie i utrzymywanie aplikacji z wykorzystaniem Docker i Jenkins.

Koncentruję się na rozwiązaniach, które usprawniają procesy biznesowe, zapewniają sprawną wymianę danych i umożliwiają dalszy rozwój systemów. Przykładem jest integracja systemów uczelnianych z Salesforce, w której zmiany danych były synchronizowane w ciągu około 5 minut.

Poza pracą zawodową rozwijam własne projekty programistyczne:

🛣️ Badania drogowe – aplikacja

Tworzę aplikację wspierającą laboratoria drogowe w wykonywaniu badań mieszanek mineralno-asfaltowych, dokumentowaniu wyników i organizacji pracy. Łączę doświadczenie programistyczne z praktyczną znajomością specyfiki pracy laboratorium drogowego.

🔭 Astronomia wielozakresowa

Rozwijam projekt oparty na danych z teleskopów kosmicznych. Pracuję nad pozyskiwaniem i przetwarzaniem plików FITS, łączeniem obrazów z różnych filtrów oraz tworzeniem podstaw bazy danych galaktyk obserwowanych w różnych zakresach promieniowania elektromagnetycznego.

Oba projekty rozwijają moje umiejętności projektowania architektury, automatyzacji przetwarzania danych i budowania aplikacji od podstaw.

Interesują mnie architektura oprogramowania, integracje systemowe i nowoczesne technologie, szczególnie tam, gdzie rozwiązania IT przekładają się na realne korzyści dla użytkowników i organizacji.

Technologie: Java, Spring Boot, React, TypeScript, REST API, SOAP, Salesforce, PostgreSQL, Microsoft SQL Server, MongoDB, Docker, Jenkins.
